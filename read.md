# 🏃 CanopyStride

A sleek, dark-themed interactive route generator built with Streamlit, PyDeck, and OpenRouteService. CanopyStride generates custom, closed-loop running and walking paths based on target distance and real-time location.

## Features
- **Loop Generation**: Generates custom circular routes for walking or hiking based on target distance.
- **Interactive Maps**: Features Light, Dark, and ESRI Satellite tile layers powered by PyDeck.
- **Turn-by-Turn Directions**: Displays detailed step-by-step navigation instructions.
- **GPX Export**: Download generated routes directly for Garmin, Strava, or Apple Watch.
- **Location Auto-Detection**: Uses browser geolocation to center routes around you.
